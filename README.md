Artic Search takes the API from the Art Institute of Chicago (also known as AIC or ARTIC) and provides 
a platform for looking at art. The user can choose either to get a radom piece of art or get a piece 
based on their birthday. 

All art in ARTIC is searchable based on an ID code. The user inputs their birthday (MMDDYY) and that
number acts as the ID. In the event that there is no ID matching the birthday, the program will default
to choosing a random artwork.

Once a button is clicked ARTIC Search displays an image along with title, artist, and description. In
the chance one of these categories doesn't exist or is labeled "null" the website will print "Unknown."
